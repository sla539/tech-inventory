# Облік техніки

Сайт для обліку принтерів, ноутбуків і витратних матеріалів. Працює на Firebase (вхід + база Firestore), публікується через GitHub Pages.

## Структура

| Файл | Статус | Призначення |
|---|---|---|
| `index.html` | **робочий** | Увесь сайт в одному файлі: розмітка, стилі, логіка, налаштування Firebase |
| `firestore.rules` | **робочий** | Правила безпеки бази. Публікуються вручну: Firebase → Firestore Database → Rules → Publish |
| `firebase.json` | запас | Налаштування для `firebase deploy` (на випадок переїзду на Firebase Hosting) |
| `app.js`, `config.js`, `seed.js`, `style.css` | **застарілі** | Залишки першої багатофайлової версії, сайтом не використовуються |

## Налаштування

Усі параметри — на початку `<script type="module">` в `index.html`:

| Параметр | Що це |
|---|---|
| `firebaseConfig` | Дані вебзастосунку Firebase (не секрет — захист забезпечують правила Firestore) |
| `ADMIN_UID` | UID головного адміністратора. **Має збігатися з `mainUid()` у `firestore.rules`** |
| `INV_DAYS` | Через скільки днів без звірки пристрій вважається «не звіреним» |
| `SITE_NAME` | Назва сайту |
| `LABEL_FOOTER` | Підпис унизу етикетки (порожньо — без смуги) |

## Ролі

- **очікує** — зареєструвався, доступу немає, поки адмін не призначить роль;
- **перегляд** — лише дивиться, може створювати заявки на несправність;
- **технік** — пристрої, видача/прийом, роботи, звірки, склад, файли, етикетки;
- **адмін** — усе, плюс видалення, користувачі, журнал дій, лічильники, графік ТО, інвентаризація.

Головний адміністратор (`ADMIN_UID`) не має запису в колекції `users` і не видимий іншим адмінам.

## Колекції Firestore

`users` · `devices` · `events` (історія, незмінна) · `stock` (склад) · `files` (фото й файли до ~0,9 МБ) · `requests` (заявки) · `audit` (журнал дій, незмінний) · `counters` (лічильники принтерів) · `maint` (графік ТО) · `inv` (сесія інвентаризації)

## Локальний запуск

Подвійний клік по `index.html` не спрацює (браузер блокує модулі з файлів). Потрібен локальний сервер:

```powershell
python -m http.server 8080
```

Потім відкрити http://localhost:8080. Домен `localhost` має бути в Firebase → Authentication → Settings → Authorized domains (він там за замовчуванням).

## Публікація

1. Зміни в `index.html` → коміт і `git push` у гілку `main` → GitHub Pages оновлюється автоматично за 1–2 хв.
2. Зміни в `firestore.rules` → **окремо** вставити в Firebase Console → Firestore Database → Rules → Publish. GitHub правила не публікує.

## Плани

- Переїзд на домен компанії.
- Прибрати початкові дані (`SEED_DEVICES`, `SEED_STOCK`) з `index.html` після підтвердження, що вони в базі.
- Вимагати підтвердження email під час самореєстрації.
